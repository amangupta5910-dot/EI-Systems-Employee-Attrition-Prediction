# 🤖 AI Powered Employee Attrition Prediction System

An AI-powered Employee Attrition Prediction System developed using **Machine Learning**, **Python**, and **Streamlit**. This project predicts whether an employee is likely to leave the organization based on HR-related features and provides AI-generated insights, recommendations, and interactive visualizations.

---

## 📌 Project Overview

Employee attrition is one of the major challenges faced by organizations. This project helps HR professionals identify employees who are at risk of leaving by using a trained Machine Learning model.

The application provides:

- Employee Attrition Prediction
- Prediction Confidence Score
- Attrition Risk Gauge
- AI Insights
- AI Recommendations
- Interactive Charts
- Employee Summary Report
- CSV Report Download

## 📊 Dataset

**IBM HR Analytics Employee Attrition Dataset**

The dataset contains employee-related information such as:

- Age
- Department
- Gender
- Job Role
- Monthly Income
- Business Travel
- Job Satisfaction
- Environment Satisfaction
- Work Life Balance
- Overtime
- Total Working Years
- Years At Company

and several other HR-related features.

## ▶️ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/Employee-Attrition-Prediction.git
```

Move to the project folder

```bash
cd Employee-Attrition-Prediction
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
